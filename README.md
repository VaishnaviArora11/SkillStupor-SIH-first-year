# 🚀 SkillStupor

### An AI-Powered Career Development & Skill Verification Platform

CareerTwin is an automated, skill-focused professional networking platform inspired by LinkedIn. Its primary goal is to help students **discover, develop, verify, and showcase their skills**, making them more visible and accessible to recruiters.

Unlike traditional professional networking platforms, CareerTwin focuses on **verified skills, career readiness, personalized roadmaps, and intelligent student–company connections**.

---

## 🎯 Vision

To bridge the gap between students and recruiters by transforming academic and self-learned skills into **verified, career-ready profiles**.

CareerTwin aims to:
- Automate professional profile and resume creation.
- Verify student skills through in-app assessments and practical tests.
- Recommend career paths, internships, and jobs based on individual goals.
- Help companies discover suitable candidates, including students who have not applied.
- Connect companies, branches, and employees through an interconnected organizational network.

# 🪪 Verified Skill Passport

The Skill Passport is a verified record of a student's capabilities.

Unlike traditional profiles where users can manually list skills, CareerTwin aims to add skills based on **verified in-app assessments, practical tests, projects, and other defined evidence**.

### Example

```text
┌────────────────────────────┐
│       SKILL PASSPORT       │
│                            │
│ Python             ✓       │
│ DSA                ✓       │
│ Git                ✓       │
│ SQL                ◐       │
│                            │
│ Projects: 4                │
│ Certifications: 3         │
│ Internships: 1            │
│                            │
│ Verification: 87%          │
└────────────────────────────┘
```

### Verification System
- In-app skill assessments
- Practical coding tests
- Project-based evidence
- Certification records
- Internship and experience records
- Skill verification status
- Periodic reassessment

> Verification percentages and skill badges would be determined by a transparent scoring system developed for the platform.

# ⚠️ Important Considerations

CareerTwin is designed around responsible and transparent automation.

Future implementation should consider:
- Student consent and privacy
- Secure handling of GitHub and profile data
- Transparency in skill verification
- Fairness in candidate matching
- Explainable compatibility scores
- Protection against inaccurate AI-generated claims
- Employer access controls
- Student control over profile visibility
